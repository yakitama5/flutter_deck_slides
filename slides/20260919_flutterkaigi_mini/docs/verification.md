# 描画・動作確認

確認日: 2026-09-13（JST）

## 実行環境

- Flutter 3.47.1 / Dart 3.13.1
- flutter_scene 0.23.0
- Web: ローカルWebアプリをブラウザで操作。FlutterScene内蔵WebGL2バックエンド。
- macOS: ビルドしたアプリを起動して操作。Impeller / Metal + Flutter GPU。
- 実際の `assets/models/dashmaru.glb` をビルドフックで変換し、`loadScene` でロード。

## 参考画像との比較と修正

提供された三面図、8方向のモデリング画像、ぬいぐるみ写真を読み、実描画を正面・横・後ろから比較した。
立ち姿は三面図に合わせ、座った3D資料とぬいぐるみは厚みの参考にした。

1. 胴体の奥行きを増やし、三面図にあるほぼ球体のシルエットへ修正。
2. 三面図から基本6色を採色して材質を修正。
3. 最初の描画では翼が正面から細いヒレ状に見えたため、翼面を外へ傾け、張り出しを増加。三枚の羽先が正面・横の両方で見えるようにした。
4. 顔が遠近法で大きく見えたため、カメラを遠ざけて画角を狭め、顔マスクも微調整。
5. 胸が灰色、赤い丸が暗赤色に見えたため、一定の拡散環境光を設定。環境設定による光の上書きも修正し、白い胸とピンクの丸を回復。
6. まばたきの完全閉眼フレームで目が細すぎたため、閉じたまぶたの黒い弧を追加。遠くからでも閉眼が見えるように調整。

比較用のスクリーンショットはローカルの `docs/screenshots/` に保存。
参考画像・確認画像はGit管理対象から外し、作成したGLBモデルを管理対象にしている。

## 4種類の動き

両プラットフォームで実際に選択・再生し、複数時点の描画を目視確認した。

| 動き | 確認した描画 |
|---|---|
| 歩く | 横から左右の足が交互に前へ出る。胴体の上下動と羽の振りを確認 |
| ジャンプ | 溜めから浮上し、台から足が離れる。羽が開き、着地で元の高さへ戻る |
| 手を振る | 片翼が上がり、繰り返し角度が変わる。胴体も軽く傾く |
| まばたき | 両目が丸い状態から細い形へ閉じ、再び開く。青い顔マスクは動かない |

完全な閉眼は `?motion=Blink&time=0.561&camera=front` でも確認した。
macOSでも0.5倍速のライブ再生で黒いまぶたの弧を確認した。

併せて、動作切り替え、一時停止と再開、0.5倍速、正面・横・後ろ、ドラッグ回転、自動回転、リセットを確認。
macOSでは一時停止後の複数スクリーンショットで同じ歩行ポーズが保持されることも確認した。
Webの確認時コンソールに警告・エラーなし。macOSにも実行時例外なし。
