# FlutterKaigi mini — だしゅまると Flutter Scene

2026-09-19 FlutterKaigi mini 向けに育てていく、だしゅまるの3Dデモです。
Flutter / Dart と `flutter_scene 0.23.0` でモデルを描画し、GLB内の
歩く・ジャンプ・手を振るなどの8種類に、うなずく・首かしげ・おじぎ・よろこぶ・きょろきょろ・のびを加えた14種類の動きと、
通常・笑顔・ぐるぐる目・踏ん張るの4種類の表情を組み合わせられます。
ジャンプでは離陸前と着地後を通常の表情にし、空中で羽ばたく間だけ踏ん張る表情へ切り替えます。

[公開デモ](https://yakitama5.github.io/flutter_deck_slides/20260919_flutterkaigi_mini/)
は、`main` へのマージ後に既存のGitHub Pagesワークフローで更新されます。

## 起動

リポジトリで指定している Flutter 3.47.1 / Dart 3.13.1 を使います。
GLBと生成ソースはGit管理対象外です。事前に[非公開アセットの復元](../../docs/private-assets.md)で
GPGとパスフレーズを準備してください。

```sh
# リポジトリルート
mise install
python3 tool/private_assets.py restore --passphrase-file .private-assets/dashmaru.passphrase
flutter pub get
cd slides/20260919_flutterkaigi_mini
flutter run -d chrome
```

macOS でも起動できます。Flutter GPU の有効化設定は同梱済みです。

```sh
flutter run -d macos
```

WebはFlutterSceneに内蔵されたWebGL2バックエンド、macOSはFlutter GPU / Impellerで描画します。
初回はビルドフックでモデルの事前変換とシェーダーのコンパイルが走ります。
参考画像フォルダはアセット探索対象から外しており、配布物へ混入しません。

## 操作

- 「歩く」「ジャンプ」「手を振る」「まばたき」「待機」「走る」「ぶんぶん」「座る」で動きを切り替えます。
- リアクションには「うなずく」「首かしげ」「おじぎ」「よろこぶ」「きょろきょろ」「のび」を選べます。
  すべてマスターGLB内のアニメーションで、他の資料からも同じクリップを再利用できます。
- 「通常」「笑顔」「ぐるぐる」「踏ん張る」で表情を選びます。
  ジャンプでは通常→踏ん張る→通常と自動で切り替わり、別の動作へ切り替えると選択した表情へ戻ります。
  ジャンプ中に選び直した表情も、その後の動作へ引き継ぎます。
- 起動時は「待機」です。切り替え時は0.3秒かけて前後の動きを混ぜ、柔らかくつなぎます。
- 「座る」は一度腰を下ろした後、座ったまま呼吸や小さな揺れを繰り返します。
  別の動作を選ぶまで立ち上がりません。
  切替時は座り込みの経路を逆にたどって立ち上がり、選んだ動作へ移ります。
  立ち上がり途中の一時停止・速度変更や、行き先の選び直しにも対応します。
- 再生・一時停止、再生速度の変更ができます。
- ドラッグで視点を回転し、スクロールで拡大・縮小します。
- 正面・横・後ろの視点と、自動回転を使って立体を確認できます。
- 背景は「ミント」「スタジオ」「ピーチ」「夜」の4種類です。背景と台座の色を変え、動作・表情・再生速度・一時停止・視点を保ちます。
- リセットで正面・通常速度・待機・通常の表情・ミントの背景に戻ります。
- キー `1`〜`8` はカード順に歩く・ジャンプ・手を振る・まばたき・待機・走る・ぶんぶん・座る、`Space` は再生／一時停止、`R` はリセットです。
- 追加動作は `9` がうなずく、`0` が首かしげ、`Q` がおじぎ、`W` がよろこぶ、`E` がきょろきょろ、`T` がのびです。各カードのツールチップにも対応キーを表示します。

同じ動作をもう一度選ぶと、その時点から再生を続けます。カードは画面幅に合わせて7列・4列・3列に折り返し、低い画面では全操作欄までスクロールできます。
ジャンプ以外の瞬きを伴う動作では通常の表情の目が開閉し、他の表情では選択した目の形を保ちます。

## モデルと参考資料

以下のGLB・マニフェスト・生成用Python 3ファイルは暗号化バンドルから復元します。
Git管理するのは暗号化ファイルで、平文のアセット・生成ソースはgitignore対象です。

- `assets/models/dashmaru.glb`: 立体形状・9種類の材質・14種類の動き・4種類の表情を内包するglTF 2.0モデル。
- `tool/build_dashmaru.py`: モデルの編集可能なソース。Python標準ライブラリだけで再生成できます。
- `tool/dashmaru_expressions.py`: 参考画像をもとにした表情の曲面メッシュ生成。
- `tool/dashmaru_materials.py`: 配色を維持しながら、身体・目・くちばしなどの反射と粗さを調整。
- `assets/models/dashmaru_manifest.json`: モデルサイズ、三角形数、クリップ一覧。
- `assets/dashmaru/`: ユーザー提供の参考資料。既存のgitignore設定を維持しています。

公式キャラクター「だしゅまる」を、提供された三面図と8方向の3Dモデリング画像を
照合して、このデモ用に立体化したものです。公式配布の3Dモデルではありません。
キャラクターの権利は元の権利者に帰属します。

立ち姿・顔の比率は `だしゅまる画像/sanmen.png`、胴体の厚み・三枚の羽先・尾・
円錐形のくちばしは `3080388 3Dモデリング/` を基準にしました。
ぬいぐるみ写真は丸みの補助資料にしています。

基本色は三面図の `#C8FCFE` / `#68D8FB` / `#634936` / `#E83568` / 白 / 黒です。
GLBの材質には線形色へ変換して格納するため、実描画では照明による陰影が加わります。
顔、胸、雪の黒い境界線と色面も、胴体・帽子の曲面に沿うメッシュです。

モデルは52メッシュ・207,534三角形・28ボーン、GLBは約11.62 MB（11,620,108バイト）です。
曲面の頂点を共有して法線を滑らかにつなぎ、羽根は厚みを持たせて身体に沿う向きにしています。
身体と羽根にはボーンの影響を重み付けしたスキニングを使い、胴体のしなりと呼吸、
付け根から羽先までの連続した曲がりを表現します。羽根の上端は胴体に追従し、
肩・中間・羽先に加えて、各区間の柔らかな変形を担う関節へ重みを分散させます。
羽根は反対側へも曲がり、遅れて追従する羽先と身体の伸縮で、柔らかな動きを表現します。
頭頂部には2関節を追加し、身体の動きに遅れてぷるぷる揺らします。
材質は `KHR_materials_specular` と粗さを組み合わせ、身体と羽根には広く柔らかい反射、
目には控えめな艶、くちばしにはサテン調の艶を加えています。黒い輪郭線はマットに保ちます。
以前の `KHR_materials_sheen` は使用していません。
くちばしと尾は閉じた丸い形状に整え、くちばしの付け根は顔の内側へ収めています。
くちばしは滑らかな曲線を回転させた曲面で、先端にも丸みを付けています。
目元の面の巻き方向を揃え、眉間で重なる黒い面を除き、笑顔や踏ん張る表情に現れていた模様を修正しています。
表情の線は太さに対して十分な曲率を持つ形にし、内側の面が自己交差しないようにしています。
富士山の輪郭にも小さな丸みを加え、側面から見たときの角を和らげています。
脚は2ボーンのIKで足の位置から膝の曲がりを求め、長さの変化も許して伸縮させます。
左右の足にはそれぞれ前足部とつま先の関節を追加し、踵の接地からつま先の蹴り出しまで連続して曲げます。

モデル座標はY軸が上、Z軸の正方向が正面、足裏がほぼY=0、高さ3.04です。
FlutterSceneの読み込み時の座標変換に合わせ、アプリではZ軸の負方向から正面を見ます。

## 再生成と検証

復元したローカルの生成ソースを編集し、検証後に[暗号化バンドルを更新](../../docs/private-assets.md#モデルを更新するとき)します。

```sh
# このディレクトリで実行
python3 tool/build_dashmaru.py
python3 tool/check_dashmaru.py
flutter test
flutter analyze
flutter build web
```

接地を詳しく検証する場合は `python3 tool/check_dashmaru.py --subframes 3` を実行します。
各キー間の1/4・1/2・3/4の姿勢も補間し、全14動作で実際の足メッシュ頂点を調べます。
座る動作では腹部と脚も調べ、床へ貫通せず、足を前に出した座位を保持することを検証します。
2.4秒と6.4秒の全トラックの一致と、その間の全641姿勢で座り続けることも確認します。
位置・スケールはLINEAR、回転はSLERPで評価するため、通常のキーフレーム検証より時間がかかります。

モデルを変更したらアプリを再起動して、ビルドフックの変換を反映させてください。
GLBはBlender等のglTF対応モデラーでも読み込めます。

歩行は1.4秒の周期と既存トラックのキーフレーム時刻・補間方式、上半身の姿勢を維持しています。
足裏を自然に転がすため、脚・膝・足首の姿勢は改良し、前足部・つま先の動きを追加しています。
`--baseline` はこの範囲を比較し、その他の追加トラックが歩行中に中立姿勢を保つことも検証します。
改良前のモデルとの比較は、リポジトリルートで次のように実行できます。
比較用GLBは一時ファイルとして扱います。

```sh
git show b1eb112b661a5fb2451a696c377c0879bd4e76da:slides/20260919_flutterkaigi_mini/assets/models/dashmaru.glb > /tmp/dashmaru-walk-baseline.glb
python3 slides/20260919_flutterkaigi_mini/tool/check_dashmaru.py --baseline /tmp/dashmaru-walk-baseline.glb
```

| 動作 | 周期 | 内容 |
| --- | --- | --- |
| `Walk` | 1.4秒 | 既存の上半身のリズムを保った連続歩行。踵から接地し、前足部とつま先を曲げて蹴り出します。 |
| `Jump` | 2.4秒 | 通常の表情で溜めて離陸。空中で羽ばたく間だけ目をぎゅっと閉じ、着地後は通常の表情に戻ります。 |
| `Wave` | 3.2秒 | 身体を傾けて片翼を上げ、中間・羽先を遅れてしならせるバイバイ。途中で瞬きします。 |
| `Blink` | 2.2秒 | 待機の小さな揺れに、二回の瞬きを重ねます。 |
| `Idle` | 4.8秒 | 呼吸、身体・羽根・尾の小さな揺れ、ときどきの瞬きです。 |
| `Run` | 0.76秒 | 身体を左右に振る、とてとてした走り。つま先を曲げて蹴り出し、両脚が浮く区間には羽根もばたつきます。 |
| `Shake` | 2.8秒 | 左右にぶんぶん振り、身体・羽根・頭頂部が遅れてぷるぷる揺れます。 |
| `Sit` | 初回2.4秒＋4秒周期 | 腰を下ろし、両足を前へ出してちょこんと座ります。以降はクリップの2.4〜6.4秒を繰り返し、座ったまま呼吸・羽先・頭頂部が小さく動きます。 |
| `Nod` | 2.6秒 | 身体ごとぐっと沈みながら、頭を大きく振って2回うなずきます。勢いよく納得するリアクション。 |
| `Tilt` | 3.4秒 | 両足を着けたまま少し傾き、片翼を頬の横へ寄せて「はて？」と考えます。瞬きを挟み、ゆっくり立ち姿へ戻ります。 |
| `Bow` | 3.2秒 | 予備動作から身体を深く折っておじぎし、しっかり止まってから立ち姿へ戻ります。挨拶や感謝に。 |
| `Celebrate` | 3.0秒 | しゃがんで勢いをつけ、両翼を上げて2回ぴょんぴょん跳びます。着地で身体を弾ませる、笑顔に合うリアクション。 |
| `LookAround` | 4.2秒 | 正面を向いたまま左右へ小さく踏み出し、片翼を開いて「あっちかな、こっちかな」と探します。各ステップで足を着け、中央へ戻ります。 |
| `Stretch` | 4.0秒 | 身体を縮めてから両翼を頭上へ伸ばし、ぐーっと背伸びして力を抜きます。 |

追加6動作は中立姿勢で始まり、中立姿勢へ戻って繰り返します。
`Celebrate` は両足が離れる2回のジャンプ、`Nod`・`Tilt`・`Bow`・`Stretch` は両足を接地させたリアクションです。
`LookAround` は足を少し上げて横へ踏み出し、次のステップまで両足を着けます。
`Tilt`・`LookAround` は頭と胴体を一体で扱い、前後や左右へひねらず、拡大縮小もしません。
お腹の中央の模様を正面に見せたまま、足・羽・瞬きでリアクションを表します。
座位からの立ち上がりにも既存の切替処理を使います。
`python3 tool/check_dashmaru.py --preserve-existing <追加前のGLB>`で、既存8クリップの全トラック・時刻・補間方式が変わっていないことを検証できます。

全クリップが共通の89トラックを持ち、関節・目・胴体を同じ構成で制御します。
アプリはFlutterSceneのクリップの重みを補間し、切り替え途中に別の動作を選んでも、
そのときの混合状態から次の動作へつなぎます。歩行・走行は周回時にも動きを止めません。
座位からの切替では、低い腰の姿勢と歩行を直接混ぜると足が床へ沈むため、
接地を確認した入口経路を逆再生して立ち上がります。
中立から始まる動作へは同じ姿勢のまま接続し、歩行・走行へは専用の入口姿勢を経由します。
表情のグループはアニメーションの制御対象から外しています。
手動で選んだ表情を保持しつつ、ジャンプでは空中で羽ばたく区間に合わせ、クリップの正規化時間が0.23以上・0.81未満
（2.4秒のうち0.552秒以上・1.944秒未満）の間だけ踏ん張る表情を表示します。
それ以外のジャンプ区間は、手動の選択にかかわらず通常の表情になります。
表情の判定にはFlutterSceneの実際の `AnimationClip.playbackTime` を使い、
シーク、一時停止、再生速度の変更、ループ後も動きと同期させています。

再現可能な静止フレーム確認にはURLクエリを利用できます。

```text
?motion=walk&time=0.3&camera=three-quarter
?motion=jump&time=0.7&camera=front
?motion=wave&time=1.0&camera=front
?motion=blink&time=0.748&camera=front
?motion=idle&time=1.2&camera=three-quarter
?motion=run&time=0.3&camera=three-quarter&expression=smile
?motion=shake&time=1.1&camera=front&expression=spiral
?motion=idle&time=0&camera=front&expression=strain
?motion=idle&time=0&camera=three-quarter&zoom=2
?motion=sit&time=3.2&camera=three-quarter&background=peach
?motion=sit&time=120&camera=three-quarter&background=peach
?motion=nod&time=0.832&camera=three-quarter
?motion=tilt&time=1.5&camera=front
?motion=bow&time=1.4&camera=three-quarter
?motion=celebrate&time=1.1&camera=front&expression=smile
?motion=lookaround&time=2.8&camera=front
?motion=stretch&time=2.0&camera=three-quarter
```

`time` は秒で、その時刻へ移動して一時停止します。
座る動作で6.4秒を超える時刻を指定すると、初回の座り込み後の4秒ループ内へ移動します。
`zoom` は標準視点に対する倍率です。`zoom=2` で顔や表面を拡大して確認できます。
有限の正の値を受け付け、実際の倍率は0.75〜約2.667倍に制限します。省略時や無効な値は1倍です。
`expression` は `normal`・`smile`・`spiral`・`strain` を指定できます。
`background` は `mint`・`studio`・`peach`・`night` を指定できます。省略時・無効値は `mint` です。
以前の `deadpan` を指定したURLは通常の表情として読み込みます。
ジャンプでは指定した表情より上記の自動切り替えを優先し、別の動作へ移ると指定した表情へ戻ります。
描画比較と動作確認の記録は `docs/verification.md` にまとめます。
