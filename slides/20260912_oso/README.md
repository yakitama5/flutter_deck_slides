# リスくんと ひとつのどんぐり

Issue #28で作成した絵本候補から選定した画像を、通常の説明スライドとつないだ
FlutterDeckです。絵本から始まり、絵本を見終えたところで自己紹介・メッセージ・
モデルとなった体験・持ち帰り・会社紹介へ移る構成になっています。

読み聞かせ用のスピーカーノートを設定しています。原稿は `lib/speaker_notes.dart` に
まとめているので、読み聞かせる文章だけを変更する場合は、このファイルを編集してください。

会社紹介では、ピープルソフトウェアで「ちいさなキッカケ」を見つける環境を紹介します。
モデルとなった体験のスライドは、Flutterを始めたきっかけから、岡山.Flutterや
FlutterKaigiのコアスタッフにつながるまでの流れを掲載しています。

## デザインの構成

絵本の後に続く説明スライドは、広い会場での投影を前提に 1920x1080 の固定キャンバス上で
組み立て、表示サイズに合わせて拡大縮小しています。ウィンドウサイズに関係なくフォントの
大きさが変わらないので、「会場の後ろから読めるか」を 1 箇所で決められます。

- `lib/theme.dart` — 配色(絵本カバーの深緑をシードにした Material 3 の ColorScheme)、
  文字サイズの倍率、固定キャンバス、全スライド共通の枠(見出し・背景の飾り)
- `lib/widgets.dart` — 各スライドの中身(自己紹介・メッセージカード・成長ステージなど)
- `lib/main.dart` — スライドの並びと、各スライドに載せる文言

文字を全体的に大きく / 小さくしたい場合は `lib/theme.dart` の `_osoFontSizeFactor`、
色味を変えたい場合は `osoSeedColor` と `osoAccentColor` を調整してください。

## 差し替えが必要な画像

以下の 2 枚はプレースホルダーです。**同じパス・同じファイル名のまま**上書きしてください
(`pubspec.yaml` にファイル名を直接書いているため、名前を変えるとビルドが通りません)。

| パス | 用途 | 推奨 |
| --- | --- | --- |
| `assets/profile/avatar.png` | 自己紹介のアバター写真 | 正方形。円形に切り抜いて表示 |
| `assets/company/people_software.png` | 会社紹介の写真 | 横長。画面上部 54% に `BoxFit.cover` で全面表示 |

差し替え忘れではなく「ファイル名を変えてしまった」場合は、`flutter test` の
`the speaker supplies the portrait and the sponsor photo` で検出されます。

## スライド構成

- 01: 絵本の前カバー(タイトル文字は載せず、絵本のアイコンと箔押し風の装飾のみ)
- 02–13: 絵本本文 12ページ
- 14: 絵本の裏表紙
- 15: 「ご清聴ありがとうございました」→次のステップで「とはいかず……」
- 16: 絵本から、現実の話へ(説明パートへのブリッジ)
- 17: 自己紹介
- 18: 絵本で伝えたかったこと
- 19: 絵本のモデルとなった話
- 20: 持ち帰り
- 21: 会社紹介
- 22: ご清聴ありがとうございました！

絵本から始まり、絵本が終わった直後にいったん「ご清聴ありがとうございました」を
表示します。次のステップで「とはいかず……」を表示し、説明パートへつなげます。
通常スライドは Material 3 のカードを使った軽いフェードで切り替わり、
前カバーから本文へ入る時は本を開き、本文から裏表紙へ出る時は本を閉じます。
本文中は従来どおりページめくりと線画からのインク・水彩リビールが動きます。

最後の「ご清聴ありがとうございました！」は 15 の偽エンディングと同じ配色・同じ文字サイズに
してあります。同じ画がもう一度出ることで、絵本の締めくくりとして着地します。
