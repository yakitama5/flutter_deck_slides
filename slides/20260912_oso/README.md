# リスくんと ひとつのどんぐり

Issue #28で作成した絵本候補から選定した画像を、通常の説明スライドとつないだ
FlutterDeckです。絵本から始まり、絵本を見終えたところで自己紹介・メッセージ・
モデルとなった体験・持ち帰り・会社紹介へ移る構成になっています。

読み聞かせ用のスピーカーノートを設定しています。原稿は `lib/speaker_notes.dart` に
まとめているので、読み聞かせる文章だけを変更する場合は、このファイルを編集してください。

会社紹介では、ピープルソフトウェアで「ちいさなキッカケ」を見つける環境を紹介します。
モデルとなった体験のスライドは、Flutterを始めたきっかけから、岡山.Flutterや
FlutterKaigiのコアスタッフにつながるまでの流れを掲載しています。

## スライド構成

- 01: 絵本の前カバー
- 02–13: 絵本本文 12ページ
- 14: 絵本の裏表紙
- 15: 「ご清聴ありがとうございました」→次のステップで「とはいかず……」
- 16: 絵本のモデルとなった話・伝えたかった内容へのブリッジ
- 17: 自己紹介
- 18: 絵本で伝えたかったこと
- 19: 絵本のモデルとなった話
- 20: 持ち帰り
- 21: 会社紹介
- 22: ご清聴ありがとうございました

絵本から始まり、絵本が終わった直後にいったん「ご清聴ありがとうございました」を
表示します。次のステップで「とはいかず……」を表示し、説明パートへつなげます。
通常スライドは Material 3 のカード・チップを使った軽いフェードで切り替わり、
前カバーから本文へ入る時は本を開き、本文から裏表紙へ出る時は本を閉じます。
本文中は従来どおりページめくりと線画からのインク・水彩リビールが動きます。
