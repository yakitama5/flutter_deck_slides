# そのFlutterコード、なぜ書いた？

2026-09-19 FlutterKaigi mini 向けLTのFlutterスライドと読み上げ原稿です。
持ち時間は10分。本編はデモと場面転換を含めて5分（300秒）を目安にしています。
全13場面を`flutter_deck`で実装し、だしゅまるの3Dデモをスライドに組み込んでいます。

## 起動と操作

リポジトリで指定するFlutter 3.47.1 / Dart 3.13.1を使います。
初めて起動するときは、[非公開モデルの復元手順](../../docs/private-assets.md)に沿ってだしゅまるのアセットを準備してください。テストとWebビルドでも同じアセットが必要です。CIではGitHub Secretsを使って自動復元します。

```sh
# リポジトリルート
mise install
flutter pub get
cd slides/20260919_flutterkaigi_mini_lt
flutter run -d chrome
```

`web/index.html`はビルド前のテンプレートなので、ファイルを直接開いても表示できません。ローカルでは上記の起動コマンド、共有時はPRに掲載されるデプロイ済みプレビューURLを使います。

WebはFlutter SceneのWebGL2バックエンドで3Dモデルを描画します。
左右の矢印キーと画面のスライド操作ツールバーで移動でき、各場面に読み上げ原稿と目安の秒数を発表者ノートとして設定しています。

05は公式紹介動画のサムネイルを押すとスライド内で再生します。動画を見せながら説明でき、ページを進めると再生を停止します。
06のデモでは「手を振る」「走る」「ぶんぶん」「ジャンプ」のボタンと再生・一時停止を使います。「走る」は踏ん張る表情です。「ジャンプ」は空中で羽ばたく間だけ踏ん張り、それ以外は通常の表情です。
モデルをドラッグすると視点が回転し、スクロールすると拡大・縮小します。
07以降はスライド送りに合わせて動作と表情が切り替わります。
端末のアニメーション抑制設定が有効な場合、自動の動きを止め、デモボタンによる操作で動かせるようにしています。

## デザインと実装

- **テーマ**：`MaterialTheme`で生成するMaterial 3の`ColorScheme`を使います。イベント画像に合わせた濃紺（`#082B53`）のダークテーマです。コーラルをprimary、シアンをsecondary、黄色をtertiaryへ割り当てています。
- **書体**：Noto Sans JPの可変フォント（100–900、全字形）を`assets/fonts/`に同梱しています。本文400、見出し600–700を使い、可変ウェイトを明示しています。
- **画面**：1920×1080の論理サイズを16:9で拡縮します。白い本文と大きな問いを濃紺に載せ、画面の端に斜めの帯・細い輪郭線・円弧・ドットを薄く配置します。タイトルの強調はコーラルから黄色のグラデーションです。
- **自己紹介**：場所・コード・ゲームのアイコンに、Okayama、Flutter / Dart / Web、SSBU(スマブラSP) / 個人開発を対応させます。X（Twitter）へのQRコードを添えています。
- **見せ方**：前半はFlutter Sceneの進化とだしゅまるのデモ、後半は技術の使いどころと、作業中に選んだ理由を考える習慣を扱います。04は本人提供の2026/03の発表資料画像、05はFlutter Scene公式の紹介動画を使います。

画面の文案・レイアウトは`lib/slides.dart`で編集します。

## 共有モデルとビルドフック

3Dシーンの実装は、隣の[だしゅまるデモ](../20260919_flutterkaigi_mini/README.md)のパッケージを参照します。
モデルの編集元も、同デモの`assets/models/dashmaru.glb`です。

依存先のデモのビルドフックがGLBをFlutter Scene向けに変換し、生成されたアセットをパッケージ経由で利用します。
LT側にはモデルや変換処理を複製せず、編集元を一つにしています。
初回ビルドではモデルの変換とシェーダーのコンパイルが走ります。
モデルを調整するときは元のデモ側を更新してから、LTを再ビルドします。
